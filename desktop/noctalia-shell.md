# Noctalia Shell
Noctalia — это оболочка на базе quickshell (панель/док), которая дополняет Niri, предоставляя визуализацию воркспейсов и системную информацию.
 * Настройка стиля: Используются CSS-подобные конфиги.
 * Модули: Настройка вывода заряда батареи, яркости экрана, статуса сети через NetworkManager и т.д.
