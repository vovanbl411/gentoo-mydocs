# Специфика ASUS ExpertBook B5402CBA

Тонкая настройка уникальных функций ноутбука для работы в Gentoo (ядро 12th Gen Intel / Alder Lake).

## 1. Конфигурация ядра (Kconfig)

Для полноценной поддержки железа ASUS в ядре включены следующие модули:

- `CONFIG_ASUS_NB_WMI=m`: Основной драйвер для ноутбуков ASUS (горячие клавиши, Bluetooth, Wi-Fi).
- `CONFIG_ASUS_ARMOURY=m`: Поддержка специфичных функций управления питанием и режимами (аналог Armoury Crate).
- `CONFIG_ASUS_WMI_DEPRECATED_ATTRS=y`: Требуется для совместимости с некоторыми старыми утилитами управления.

## 2. Управление питанием и батареей (TLP)

Для продления жизни аккумулятора при работе от сети используется ограничение порога заряда до 80%.

### Текущий статус (BAT1)

Согласно данным tlp-stat, батарея в системе определяется под индексом BAT1.

Настройка через TLP (`/etc/tlp.conf`):

```bash
# Ограничение заряда для ASUS
STOP_CHARGE_THRESH_BAT1=80
```

Ручное управление через sysfs:

```bash
echo 80 | doas tee /sys/class/power_supply/BAT1/charge_control_end_threshold
```

> **Примечание по системной службе**: tlp.service отображается как inactive (dead) — это нормальное поведение. Служба запускается только в моменты смены источника питания или при загрузке, чтобы применить настройки, и не висит в памяти постоянно.

## 3. Функциональные клавиши и индикация

Работа клавиш Fn и системных индикаторов обеспечивается модулем asus-nb-wmi.

- **Подсветка клавиатуры**: Регулируется через `/sys/class/leds/asus::kbd_backlight`.
- **Мультимедиа клавиши**: В тайловом композиторе (Niri) обработка нажатий настроена через binds, вызывающие:
  - `light` — Для управления яркостью дисплея.
  - `wpctl` — Для управления звуковыми потоками Pipewire.

## 4. Состояние аккумулятора (Мониторинг)

Текущие показатели износа (на апрель 2026):

- **Design Capacity**: 5260 mAh
- **Full Charge Capacity**: 4827 mAh
- **Health (Capacity)**: ~91.8%
- **Cycle Count**: 99

### Тонкий момент по asus-armoury

Так как у тебя в ядре включен `CONFIG_ASUS_ARMOURY=m`, ты можешь установить утилиту asusctl (если она есть в оверлеях) или использовать rog-control-center. Даже если это бизнес-серия ExpertBook, эти инструменты часто позволяют управлять профилями охлаждения (Fan Curves) и лимитами процессора более гибко, чем стандартный ACPI.
