## Предпосылки

**Система:** Gentoo Linux  
**Оконный менеджер:** Niri (Wayland)  
**Тема:** Noctalia (кастомная цветовая схема)  
**Проблема:** GTK4-приложения не применяют цвета Noctalia, прозрачные окна, артефакты отображения

### Исходные данные
- Noctalia Shell генерирует `noctalia.css` с цветовой схемой
- `adw-gtk3-dark` установлен как системная тема
- `nwg-look` используется для переключения тем

---

## Диагностика проблемы

### Шаг 1: Проверка структуры темы adw-gtk3-dark

```bash
ls -la /usr/share/themes/adw-gtk3-dark/gtk-4.0/
```

**Обнаруженная проблема:** Файл `gtk-dark.css` содержит только:
```css
@import url("noctalia.css");
```

При этом `noctalia.css` отсутствует в `/usr/share/themes/adw-gtk3-dark/gtk-4.0/`, так как находится в `~/.config/gtk-4.0/`.

**Результат:** GTK4 не находит импортируемый файл → не применяются цвета фона → прозрачное окно.

### Шаг 2: Проверка локальной конфигурации

```bash
ls -la ~/.config/gtk-4.0/
```

**Обнаруженные проблемы:**
- Симлинки на системную тему вместо локальных файлов
- `gtk-dark.css` → `/usr/share/themes/adw-gtk3-dark/gtk-4.0/gtk-dark.css` (битый импорт)
- `gtk.css` содержит импорты GTK3-файлов (`libadwaita.css`, `libadwaita-tweaks.css`)

### Шаг 3: Проверка типа приложений

```bash
# Проверка GTK3 vs GTK4
ldd $(which nwg-look) | grep -E "gtk-3|gtk-4"
ldd $(which pavucontrol) | grep -E "gtk-3|gtk-4"

# Проверка libadwaita
ldd $(which pavucontrol) | grep adwaita
```

**Результаты:**
- `nwg-look` — GTK4 + libadwaita
- `pavucontrol` — чистый GTK4 (без libadwaita)

## Пошаговое решение

### Этап 1: Восстановление системной темы

**Проблема:** Системная тема `adw-gtk3-dark` содержит пользовательские правки с битыми импортами.

**Решение:**
```bash
# Удаление пакета с очисткой
sudo emerge --unmerge adw-gtk3

# Ручная очистка остатков
sudo rm -rf /usr/share/themes/adw-gtk3-dark/

# Переустановка
sudo emerge adw-gtk3
```

**Проверка:**
```bash
cat /usr/share/themes/adw-gtk3-dark/gtk-4.0/gtk-dark.css
# Должен содержать стандартный CSS без @import noctalia.css
```

### Этап 2: Создание локальной конфигурации GTK4

**Принцип:** GTK4 игнорирует `gtk-theme-name` для CSS. Использует только `~/.config/gtk-4.0/gtk.css` и `gtk-dark.css`.

**Действия:**
```bash
cd ~/.config/gtk-4.0/

# Удаление старых симлинков
rm -f gtk.css gtk-dark.css

# Создание gtk.css
cat > gtk.css << 'EOF'
@import url("noctalia.css");
EOF

# Создание gtk-dark.css (идентичен gtk.css)
cat > gtk-dark.css << 'EOF'
@import url("noctalia.css");
EOF
```

### Этап 3: Настройка noctalia.css

**Источник:** Noctalia Shell Template Processor

**Содержимое:**
```css
/*
* GTK Colors
* Generated by Noctalia's Template Processor
*/

/* Акцентные цвета */
@define-color accent_color #e6b450;
@define-color accent_bg_color #e6b450;
@define-color accent_fg_color #0b0e14;

/* Статусные цвета */
@define-color destructive_bg_color #d95757;
@define-color destructive_fg_color #0b0e14;
@define-color error_bg_color #d95757;
@define-color error_fg_color #0b0e14;

/* Основные цвета интерфейса */
@define-color window_bg_color #0b0e14;
@define-color window_fg_color #bfbdb6;
@define-color view_bg_color #0b0e14;
@define-color view_fg_color #bfbdb6;

/* Заголовки */
@define-color headerbar_bg_color #0b0e14;
@define-color headerbar_fg_color #bfbdb6;
@define-color headerbar_backdrop_color @window_bg_color;

/* Всплывающие окна */
@define-color popover_bg_color #1e222a;
@define-color popover_fg_color #bfbdb6;

/* Карточки */
@define-color card_bg_color #1e222a;
@define-color card_fg_color #bfbdb6;

/* Диалоги */
@define-color dialog_bg_color #0b0e14;
@define-color dialog_fg_color #bfbdb6;

/* Обзор/овервью */
@define-color overview_bg_color #1e222a;
@define-color overview_fg_color #bfbdb6;

/* Боковая панель */
@define-color sidebar_bg_color #1e222a;
@define-color sidebar_fg_color #bfbdb6;
@define-color sidebar_backdrop_color @sidebar_bg_color;
@define-color sidebar_border_color @window_bg_color;

/* Вторичная боковая панель */
@define-color secondary_sidebar_bg_color #0b0e14;
@define-color secondary_sidebar_fg_color #bfbdb6;

/* Нефокусированные состояния */
@define-color theme_unfocused_fg_color @window_fg_color;
@define-color theme_unfocused_text_color @view_fg_color;
@define-color theme_unfocused_bg_color @window_bg_color;
@define-color theme_unfocused_base_color @window_bg_color;
@define-color theme_unfocused_selected_bg_color @accent_bg_color;
@define-color theme_unfocused_selected_fg_color @accent_fg_color;
```

### Этап 4: Настройка settings.ini

```bash
cat > ~/.config/gtk-4.0/settings.ini << 'EOF'
[Settings]
gtk-application-prefer-dark-theme=1
EOF
```

### Этап 5: Очистка кэша и проверка

```bash
# Очистка кэша GTK4
rm -rf ~/.cache/gtk-4.0/

# Проверка цветов:
# - Фон окна: #0b0e14 (тёмно-синий)
# - Текст: #bfbdb6 (светло-серый)
# - Акценты: #e6b450 (жёлтый/оранжевый)
```

## Структура конфигурации

### Итоговое дерево файлов

```
~/.config/gtk-4.0/
├── gtk.css              # Импорт noctalia.css
├── gtk-dark.css         # Импорт noctalia.css (идентичен gtk.css)
├── noctalia.css         # Цветовая схема Noctalia
└── settings.ini         # Предпочтение тёмной темы

/usr/share/themes/adw-gtk3-dark/gtk-4.0/
├── gtk.css              # Системный файл (восстановлен после переустановки)
└── gtk-dark.css         # Системный файл (восстановлен после переустановки)
```

### Логика работы

| Файл | Назначение | Приоритет |
|------|-----------|-----------|
| `~/.config/gtk-4.0/gtk.css` | Базовые стили GTK4 | Высший |
| `~/.config/gtk-4.0/gtk-dark.css` | Стили для тёмной темы | Высший |
| `/usr/share/themes/.../gtk.css` | Системная тема | Игнорируется если есть локальная |
| `noctalia.css` | Цветовая схема | Импортируется локально |

## Особенности разных приложений

### Приложения с libadwaita (nwg-look)

**Особенности:**
- Используют `@define-color` напрямую
- Работают с CSS-переменными `:root`
- Корректно применяют импортированные цвета

**Результат:** ✅ Полная поддержка Noctalia без дополнительных правил

### Приложения с чистым GTK4 (pavucontrol)

**Особенности:**
- Не используют libadwaita
- Требуют явных CSS-правил для виджетов
- Игнорируют `@define-color` без селекторов

**Минимальные дополнительные правила:**
```css
/* Для ползунков (scale) */
scale trough {
  background-color: @card_bg_color;
}

scale highlight {
  background-color: @accent_bg_color;
}

scale slider {
  background-color: @accent_bg_color;
}
```

**Результат:** ✅ Ползунки громкости жёлтые, остальные элементы базовые

### Артефакты наложения

**Проблема:** При выборе элементов списка видны артефакты наслоения

**Причина:** Прозрачность фонов, отсутствие явного `background-color`

**Решение:**
```css
/* Убираем прозрачность и наслоение */
list row {
  background-color: transparent;
  background-image: none;
  box-shadow: none;
  border: none;
  opacity: 1;
}

list row:selected {
  background-color: @accent_bg_color;
  background-image: none;
  color: @accent_fg_color;
}
```

## Отладка

### Полезные команды

```bash
# Проверка версии GTK4
pkg-config --modversion gtk4

# Проверка зависимостей приложения
ldd $(which <приложение>) | grep -E "gtk-4|adwaita"

# Отладка CSS (показывает загружаемые стили)
GTK_DEBUG=css <приложение> 2>&1 | grep -i "error\|warning\|noctalia"

# Запуск без темы (для проверки)
GTK_THEME= <приложение> &

# Запуск с явной темой
GTK_THEME=adw-gtk3-dark <приложение> &
```

### Частые ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Прозрачное окно | Битый импорт в системной теме | Переустановить adw-gtk3 |
| Синие цвета вместо жёлтых | Приложение использует дефолт Adwaita | Добавить CSS-правила для чистого GTK4 |
| Артефакты наложения | Прозрачность в списках | Убрать opacity, задать явный background-color |
| Не применяются изменения | Кэш GTK | `rm -rf ~/.cache/gtk-4.0/` |
