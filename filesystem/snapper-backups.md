# Snapper

## 1. Настройка Snapper

Snapper управляет созданием снимков. Мы настроили его так, чтобы обычный пользователь мог создавать снимки без ввода пароля через doas.

### Создание конфигурации для корня

```bash
doas snapper -c root create-config /
```

### Настройка прав

Чтобы работать без root, отредактируйте `/etc/snapper/configs/root`:

```ini
ALLOW_GROUPS="wheel"
SYNC_ACL="yes"
```

## 2. Типы снимков

Мы используем три типа автоматизации:

- **Timeline**: Ежечасные снимки (храним последние 5-10 штук).
- **Pre/Post**: Снимки до и после обновлений системы (интеграция с Portage).
- **Manual**: Снимки перед важными ручными правками конфигов.
